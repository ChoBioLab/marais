---
name: literature-verification
description: Retrieve and verify literature and database evidence with the biomcp tools. Never cite from memory. Use for any citation or gene, variant, pathway or protein claim.
---
1. Pin the entity: gene symbol plus species, rsID/HGVS, disease, pathway or protein accession.
2. Use the biomcp tools. If unsure of syntax, run the biomcp tool with `skill list` and open the matching workflow.
3. Query with public identifiers only (see AGENTS.md privacy rules).
4. Retrieve each record before citing it. Keep PMID/DOI, title, year and which source returned it. Drop anything you cannot retrieve.
5. Flag preprints, conflicting sources, and database release or date when the tool shows it.
6. Output table: claim | evidence | PMID/DOI | source | confidence. End with UNVERIFIED items.
